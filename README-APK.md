# تجهيز يواقيت لتطبيق APK

المشروع مجهز باستخدام **Capacitor**، وليس بحاجة إلى تحويل واجهة جديدة إلى Expo. تطبيق أندرويد يستخدم نفس الواجهة والميزات والموارد الموجودة في الموقع.

## البناء التلقائي عبر GitHub Actions

يوجد workflow في:

`.github/workflows/android-apk.yml`

بعد رفع المشروع إلى GitHub:

1. ادفع الملفات إلى مستودع GitHub.
2. افتح تبويب **Actions**.
3. اختر **Build Yawaqit Android APK**.
4. اضغط **Run workflow**.
5. بعد انتهاء البناء نزّل artifact باسم `yawaqit-debug-apk`.

هذا يعطي APK تجريبيًا غير موقّع للنشر العام. للنشر في Google Play يلزم لاحقًا إنشاء مفتاح توقيع وإضافة أسرار GitHub، ولا ينبغي وضع المفتاح داخل المستودع.

## البناء محليًا

```bash
pnpm install
pnpm build
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

الملف الناتج يكون عادةً في:

`android/app/build/outputs/apk/debug/app-debug.apk`

## إشعارات الأذان والتنبيهات في الخلفية

- يطلب التطبيق إذن الإشعارات وإذن الموقع عند تشغيله داخل Android.
- تُنشأ قنوات مستقلة لأذان الفجر، وبقية الصلوات، وتذكير الذكر، وورد القرآن، وحديث اليوم.
- لكل نوع صوت مختلف محفوظ داخل `android/app/src/main/res/raw/`.
- تُجدول الصلوات الخمس باستخدام `LocalNotifications` مع `allowWhileIdle` وتوقيت دقيق، وتُحدّث بعد تحديد الموقع وإعادة فتح التطبيق.
- تُجدول كذلك تذكيرات الذكر وورد القرآن وحديث اليوم يوميًا.
- يجب السماح للتطبيق بالإشعارات وبإذن **المنبهات والتذكيرات** إذا طلبه النظام، وعدم تقييده من إعدادات توفير البطارية.

> يعمل الأذان عندما يكون التطبيق مغلقًا أو في الخلفية طالما أن الهاتف يعمل، والأذونات مفعلة، وقنوات الإشعارات غير مكتومة. لا يستطيع أي تطبيق تشغيل إشعار أثناء إيقاف الهاتف بالكامل، وقد يمنع وضع عدم الإزعاج الصوت حسب إعدادات الجهاز.

الأصوات المستخدمة:

- `adhan_fajr.mp3`: أذان الفجر.
- `adhan_madina.mp3`: أذان بقية الصلوات.
- `notify.mp3`: تذكير الذكر.
- `correct.mp3`: ورد القرآن.
- `click.mp3`: حديث اليوم.

## الصلاحيات

- يتم طلب إذن الموقع بدقة عالية عبر `@capacitor/geolocation`.
- يتم طلب إذن الإشعارات عبر `@capacitor/local-notifications`.
- تمت إضافة `POST_NOTIFICATIONS` و`SCHEDULE_EXACT_ALARM` و`WAKE_LOCK` و`RECEIVE_BOOT_COMPLETED` إلى Android.
- على الويب يبقى مسار صلاحيات المتصفح فعالًا كبديل.
- يحدد Android الموافقات النهائية وفق إصدار النظام وإعدادات المستخدم.

## مصادر المحتوى

- الأذكار المحلية: ملف حصن المسلم الموجود في `public/data/adhkar/adhkar_full_ar.json`، وعددها 132 بابًا و267 ذكرًا.
- الأحاديث: صفحة الأحاديث وحدها تستدعي صحيح البخاري وصحيح مسلم عبر API، ولا يتم تحميلها في صفحات المقتطفات الأخرى.
- الأدعية القرآنية: ثابتة محليًا ولا تعتمد على API.
- ترجمة القرآن: يتم طلبها عند اختيار لغة غير العربية مع معرفات احتياطية، وتبقى آيات القرآن المحلية متاحة عند فشل الشبكة.
